# Vega — JoseloFarias fork

Fork de Vega mantenido por **JoseloFarias**, orientado a una experiencia multimedia más útil para contenido en español y a reducir componentes no esenciales.

## Objetivos del fork

- Priorizar contenido con audio en español latino o subtítulos en español.
- Permitir filtros de idioma configurables y ocultar fuentes/contenido no deseado.
- Eliminar publicidad, telemetría, autenticación o premium cuando no sean necesarios para la función principal.
- Preservar funciones útiles como Google Cast mientras sean operativas.
- Mantener compatibilidad con upstream sin perder las modificaciones propias.

## Desarrollo

```bash
git clone https://github.com/joselofarias-byte/vega-app.git
cd vega-app
```

Use la infraestructura real definida por el proyecto para instalar dependencias, ejecutar tests y generar el build.

## Estado

**Fork en desarrollo activo.** La meta es avanzar funcionalmente sobre filtros, fuentes, privacidad y experiencia de reproducción, no sólo sincronizar upstream.
